## 泰语稿收尾：四类中文稿没有的残留

1. **链接显示文字整片没译**：312 条里 164 条还是英文普通名词（`[pressure](url)`…），
   同一 URL 还一会儿泰一会儿英。中文稿同一篇只有 23 条、全是人名/软件名/arXiv 编号。
   → 提示词补带例子的硬规则 + 新增 `link_texts_left_source()` 守卫（只查源文**小写开头**
   的链接文字，大写留给人工）。
2. **整段照抄 / 未译**：导语第 5 段整段英文、`where`、`## General references`。
3. **模型摆烂写占位标题**：`### Viscous three-dimensional periodic solutions`
   → `### คำตอบ: ไม่มีข้อมูลในบริบทนี้`。行数/链接/公式全对，只能读出来。
4. **参考书目 13 行作者名被吞掉**，另有 5 行书名留英文。

外加 13 行共 47 条链接丢失、1 处 URL 串位、1 处裸 URL、2 处行内公式被吞。
修法：`scratch/_th_fix.py` 确定性逐行替换 + 链接文字对照表补译；专名统一到泰语维基
正式条目名 `สมการนาเวียร์–สโตกส์`（原先 3 种词根 × 2 种连字符）。

**踩坑**：泰语 `ร์` 是**两个**码位（U+0E23 ร + U+0E4C ์），正则 `นาเวียร์?` 里的 `?`
只作用于紧邻的 `์`，`ร` 仍属必需 → `นาเวีย-สโตกส์` 一个都匹配不到，要写 `(?:ร์)?`。

**好消息**：Wikimedia API 的 IP 封禁解除。`wikiterm.py --lang th --scan` 一次解析
239 个词条 → 84 条泰语维基条目名，`scripts/wiki-th-terms.json` 91 → 172 条。
