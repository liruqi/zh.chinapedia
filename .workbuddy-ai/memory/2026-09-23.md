**设计要点**（完整版见 `notes/ref-pipeline.md`，这里只记最容易踩的）：

1. **映射不猜不联网**：只认条目**开头段**自己声明的英文名。
   坑一：`（英语：X）` 在正文里会反复出现（黎曼ζ函数.md 十几处，含 `Leonhard Euler`、
   `polylogarithm`），全收会把外链指到本条目自己身上 → 粗体挂着的全收、普通括号**只取第一处**。
   坑二：开头段**不能只取前 30 行**——黎曼ζ函数.md 开篇先是 `figure-row` 图块，
   声明落在第 **33** 行。
2. **锚点靠中英两版标题序列对齐**，从第一条层级对不上的地方停止信任。
   中英**文件名不一样**（`riemann_hypothesis.md` vs `黎曼猜想.md`），不能按路径配对。
3. **维基锚点两种写法**：`#Consequences` 与 `%23Consequences`（后者更多，躺在 path 里）。
   维基用下划线代替空格，github-slugger 用连字符 → 两种都试。
4. **锚点换算不出时默认保持外链**：`#CITEREF*` 指向具体参考文献，降级更差
   （英文/泰语镜像各 9/8 处）。要降级得 `--degrade-anchor`。
5. 只换 URL，显示文字不动；脚注定义（引用来源）默认不动。

### 最大的坑：`slugify` 近似 github-slugger，泰语被静默删字符

原实现用 `[^\w\s-]` 近似。中文没事，**泰语全错**：元音/声调符号是 Mn 组合字符、
`\w` 不匹配 → 被当标点删掉，`#สมการเชิงฟังก์ชันของรีมันน` 变成
`#สมการเชงฟงกชนของรมนน`，链接跳不到标题还**肉眼看不出来**。

真规则在 `node_modules/github-slugger/index.js`（v1.5.0）：
`toLowerCase().replace(regex,'').replace(/ /g,'-')`，`regex` 太大不能手抄。
等价判据：**删 P/S/C 类但保留 `-` `_`**、**不 trim**、**不合并空白**、
只有普通空格换 `-`；还要复现同页重复标题的 `-1`/`-2` 后缀（→ `slug_headings()`）。

**验证**：拿真 `github-slugger` 对全部真实标题 + 刁钻样本做差分测试，303 条 0 不一致；
该差分用例已进回归（node 不在就跳过）。
→ 教训：**要跟某个库逐字一致时别近似，去读源码，然后差分测试。**
