## 2. 哥德巴赫猜想可视化：鼠标悬停高亮蓝线 + 气泡

`docs/math/哥德巴赫猜想.md`（zh 站专属 canvas 组件；英文稿 `goldbachs_conjecture.md` 只有
213 行纯文本、没有它）。加：鼠标移到 `x + y = n` 蓝线上 → 该线加粗变深蓝（`#0d47a1`、
lineWidth 4），并在线的**上半段**（线段靠左上那头 1/4 处）弹白底气泡 `x + y = n`。

- 几何：所有 `x + y = n` 在屏幕上是斜率 1 的**平行线** `y = x + (PLOT - SCALE * n)`，点到线
  垂距 = `|my - mx - c| / √2`，取最近的一根；容差按画布显示宽度等比放大。相邻偶数线只隔
  8.34px（垂距），所以必然是「最近者胜」，偏 20px 会落到隔壁那根上。
- 把 `drawFrame` 里的 `lastEven` 抽成 `lastEvenFor(frameIdx)` 供命中测试复用 → 只高亮已经画
  出来的线。组件存**鼠标位置**而非「悬停的 n」：每帧重画时按当前位置重新命中，指针不动也能
  跟上新画出来的线。
- 验：800 帧差分（`lastEvenFor` 与原式全等）+ 线上取点/容差/线段外/未画出线断言全过；
  真 Chromium 截图 8 种情形命中全对；SSR（真 React 19）渲染通过；`npm run check` 过；
  本地 dev server 上真页面 E2E（特征色 `#0d47a1` 计数：0 / 1140 / 2967 / 0）通过。
