## 用 Siegel zero 对比 mediawiki-to-gfm（pandoc）与 scripts/wikitext2md.py

用户要求评估 `D:\SRC\M\mediawiki-to-gfm`（他之前做的 pandoc/PHP 批量转换工具）
与本项目新写的 `scripts/wikitext2md.py` 在 Siegel zero 词条上的产出质量，不做翻译。

### 环境：用户工具链跑不起来

- `php` / `pandoc` / `composer` 都不在 PATH，且 `vendor/` 从未 install。
- 解决办法：下官方 pandoc 3.1.11 Windows 二进制到 `scratch/pandoc/`，再用 Python
  **逐行复刻 `App\Convert` 的编排**（`scratch/run_mwgfm_pipeline.py`）：
  html_entity_decode → 16 KiB 长度门槛 → CleanLink 改写 `[[…]]` → 去注释 →
  pandoc `--data-dir=app --wrap=none --from=mediawiki --to=gfm+raw_html
  --lua-filter=filters/gfm-en.lua --template=cfm-en` → `str_replace('\_','_')`。
- 偏差要声明：pandoc 版本是 3.1.11 而非 README 的 2.0.x；PHP 是复刻；
  该工具本是为整站 XML dump + `../wikipedia.<lang>` 镜像设计的。

### 结论：pandoc 产物在本站无法构建

1. **MDX 编译直接失败** `Could not parse expression with acorn`——散文里 201 处
   未转义 `{`（残留 `{{cite journal|…}}`、`{{= 1}}`）。
2. **单行 `$$…$$` 吞掉全文**：pandoc 把行间公式写成一行，而 remark-math 认为
   行首 `$$` 开启 math-flow 块、直到独占一行的 `$$` 才关闭。第 24 行起 200 行
   （含全部脚注）被吃进 1 个 math 节点 → AST 里 `math:1`、`footnoteDefinition:0`。
   去掉 remark-math 单独解析则能拿到 31 条定义，正好反证。
3. **模板不展开**：`gfm-en.lua` 兜底是 `tplNames[1] .. ":" .. tplNames[2]`，
   `{{math|''q''}}` → `math:''q''`（19 处）；脚注里的 `{{cite journal}}` 是
   RawInline，管道还被转义成 `\|`（100 处）。
4. `&chi; &ge; &gamma;` 等 6 处实体未解码（`html_entity_decode` 的 HTML401 表不含）。
5. 不算 bug 的设计差异：ⓦ 标记（12）、`"wikilink"` title（84）是给整站镜像用的；
   16 KiB 门槛会静默丢弃英文短条目。

### 反过来测出 wikitext2md.py 的三个真实缺陷（已修）

1. **`<math display="inline">` 被当成行间**：旧判定 `"display" in attrs` 把
   inline 也算进去。新增 `is_display_math()`：先判 `display="inline"` → 行内；
   再判 `display` / `display="block"` → 行间；裸 `<math>` 看是否独占一行。
2. **行首 `:` 缩进让独占一行判定失效**（本篇 15 处 `： <math>`）。
   判定前先剥掉行首的 `: * # ;`。
3. **`{{math|''q''}}` 输出 `$*q*$`**：数学环境内没有斜体，先剥 `''` / `'''`。

⚠️ 修复 1 影响已生成文件：`riemann_hypothesis.md` 重跑后
**行间 14 → 57、行内 242 → 199**（脚注 54 / 表格 3 / 渲染无回归），
更贴近英文维基居中排版。`docs/math/黎曼猜想.md` 是人工翻译件，不受影响。

### 产物

### 建议（已写进报告）

两者不在一个层级：A 是整站批量流水线（XML dump → 目录树/重定向/VERSION/git），
B 是单篇精修（展开了 citation 系列、harvtxt/sfnp、sfrac/val/abs/radic/10^）。
要么给 A 加一道后置修正（三行 `$$`、清 `名字:参数`、解实体、转义 `{`、
还原脚注引文），要么保留 A 的编排、把单篇转换换成 B 的 `convert()`。

## 修复空脚注 / 无外链脚注，并重新生成 en.chinapedia 的两个英文条目

用户现象：`孪生素数.md` 脚注正常（27 条，0 空、0 无外链），`黎曼猜想.md` 脚注
"很多是空的链接，没有外链"。

### 根因：英文维基把完整书目放在 `==References==`，`<ref>` 里只写短引用

RH 的 54 个 `<ref>` 里有 18 个 `harvnb`、11 个 `harvs`、2 个 `harvtxt`，形如
`{{harvnb|Connes|2026}}`、`{{harvs|txt|first=Bernhard|last=Riemann|year=1859}}`，
完整条目（`{{citation|…|doi=…}}`）在文末。旧转换器只输出「作者 (年)」纯文本。

### 修复（`scripts/wikitext2md.py`）

1. **书目索引**：`build_bibliography()` 扫全篇 `{{citation}}`/`{{cite *}}`，
   以 `(归一化姓氏, 年份)` 建索引；`bib_lookup()` 只接受**唯一命中**避免误配。
2. **去重**：同一本书常在 `<ref>` 和 `==References==` 各出现一次 →
   `len(hits)==1` 永不成立（vonkoch/1901 有 4 条）。用 `_bib_sig()`
   （title+chapter+journal+doi+url+isbn+year 指纹）在 `build_bibliography` 内去重。
3. **`harvs` 的命名参数**：旧代码读 `pos[1]`/`pos[0]`，输出成 `txt Connes`、
   `Bernhard Riemann（1859）`。新增 `_harv_params()` 统一处理 `last=`/`first=`/
   `year1..year3`/`authorlink=`，以及 `txt` 可以在任意位置。
4. **`fmt_citation()` 补外链**：MR→mathscinet、eprint→arxiv、jstor、bibcode→ADS、
   pmid、pmc，doi 统一 `https://doi.org/`。
5. **死链处理**：`url-status=dead|usurped|unfit` 时改用 `archive-url`。
6. **`clean_field()`**（新增）：书目字段是原始 wikitext，不走正文的 math/链接转换，
   导致 Knapowski 1962 的标题把 `<math>\pi(x)-\operatorname{li} x</math>` 原样漏进
   脚注。现在解实体 + `<math>`→`$…$` + 剥 `''` + `[[a|b]]`→`b`。
   副作用（符合用户"不链 wikipedia.org"的约定）：作者/期刊不再生成维基内链。
7. **`{{mathworld}}` / `{{eom}}` 原先在 DROP_TEMPLATES 里被丢弃** → ZetaGrid 那条脚注
   丢了来源。改为渲染成 mathworld.wolfram.com / encyclopediaofmath.org 外链。
8. 行尾句号：结尾是孤零零卷号（`*Publisher* **30**`）时不再补句点，
   否则会变成 `**30**., Theorem 30`。
9. 括号式短引用（harvnb/sfnp）命中书目时也要前导空格，否则粘成
   `…pure mathematics.Bombieri, Enrico (2000)`。

## 中文版：脚注替换 + 新增 西格尔零点.md

用户选择"直接把 54 条英文脚注定义替换进去"，并要求继续生成中文版
`黎曼猜想.md` 与 `西格尔零点.md`。

### 1. 黎曼猜想.md 脚注整体替换

两个文件的脚注定义块都是**文末连续区间**，编号严格 1..54 且一一对应，
所以直接按行切片替换即可（`zh[:i0] + en[e0:e1+1] + zh[i1+1:]`），
替换前用 assert 校验编号序列，避免错位。替换后 54 条、0 空、无外链 5 条，
渲染与 MDX runtime 均无回归。

> 注意：脚注定义块前必须有空行，否则会被上一个列表吞掉（GFM 表现）。
> `黎曼猜想.md` 里定义块紧跟"外部链接"列表，靠一个空行隔开。

### 2. 新建 `docs/math/西格尔零点.md`（中文）

人工翻译 `en.chinapedia/docs/math/siegel_zero.md`，约定与 `黎曼猜想.md` 对齐：

- front matter 只有 `title:`；侧边栏是 `autogenerated`，**不用改 `sidebars.js`**。
- 维基内链一律指向 `https://en.wikipedia.org/wiki/...`，标签用中文。
- **删掉源文里 `$$` 前那些孤立的 `:` 行**（wikitext 缩进 `:` 的残留），
  `黎曼猜想.md` 里也没有这种行。
- 脚注引用写成 ` [^n]`（前导空格），脚注定义放文末、保留英文原文。
- ⚠️ **KaTeX 不渲染 CJK**：所有 `\text{…}` 里的中文都会变豆腐块。
  源文 `\text{“No Siegel zeros” for } D<0 \iff …` 这类必须把中文挪到公式外，
  `\text{splits in}` / `\text{sign of}` 等就保留英文。已加脚本核对。
- 人名：通行译名用中文（兰道、西格尔、陶哲轩、赫克、戈德菲尔德、斯塔克、
  格兰维尔、希思-布朗、林尼克…），读音不确定的保留拉丁字母
  （Tikao Tatsuzawa、P. J. Weinberger、C. Táfula），避免错译。
- 期刊/书名一律保留原文，不译。

结果：230 行、28 条脚注（0 空）、katex 477 / display 13 / `katex-error` 0 /
未渲染 `[^n]` 0 / MDX runtime OK。

### 校验清单（新增文档后用这一套）
