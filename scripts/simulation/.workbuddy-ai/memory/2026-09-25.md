## goldbachs_conjecture.py 增加 MP4 导出

- 机器上没有 ffmpeg / cv2。装 `imageio-ffmpeg`（自带 ffmpeg 二进制，venv 里）：
  `C:/Users/liruqi/.workbuddy-ai/binaries/python/envs/default/Scripts/pip.exe install imageio-ffmpeg`
  只用它的 `get_ffmpeg_exe()` 拿路径，帧通过 `-f rawvideo -pix_fmt rgb24 -i -`
  管道喂进去，**不产生中间图片文件**。
- 脚本加了 CLI 参数：`python goldbachs_conjecture.py [mp4|gif|both]`，默认 mp4。
  只有 gif 模式才把帧攒进 `frames`（800 帧 × 700×700×3 ≈ 1.2 GB 内存）；
  mp4 模式边生成边写管道，所以快很多：**mp4 12 秒 vs gif 约 1.5 分钟**。
- 编码参数：`libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart`。
  yuv420p 是兼容性关键（QuickTime/浏览器都能放），注意**宽高必须是偶数**。
  结尾补了 `TAIL_SECONDS = 2.0` 的静止帧。
- 结果：936 KB / H.264 High / 700×700 / 12fps / 1:08.67；GIF 是 8 MB，**小 8.5 倍**。
- 校验方式：`ffmpeg -i xxx.mp4`（故意不给输出文件，靠 stderr 里的 Input 信息看流信息）。

## 顺带修掉的坑

- `node scripts/build.mjs --slim` **默认输出 `build-slim/`**，不是 `build/`；
  而 `docusaurus serve .` 只认配置里的 outDir（`build/`）。
  所以「构建 → serve」要补一步把产物拷到 `build/`。
- 构建会 `clearPath` 清空 outDir；**服务正在占用该目录时会卡住**，得先停服务。
  加上沙箱批量删除保护，目录已存在时容易失败——先手动 `rm -rf` 再构建最稳。

## 加 BGM

- 用户想要 Ludovico Einaudi《Experience》。**这是受版权保护的商业录音，不能下载**。
  改成了程序合成的等价风格曲目（见 `math/bgm.py`），并明确告知用户。
- `bgm.py`：D 小调、50 BPM、Dm–B♭–F–C 循环、八分音符琶音 + 低音踏板。
  钢琴音色 = 谐波叠加 + 轻微非谐性 `1+0.0006k²`（钢琴味的关键）+ 高次谐波衰减更快
  + 快 attack；混响用**合成的指数衰减噪声做 IR，FFT 卷积**（别写 Python 循环 IIR，3M 采样太慢）。
  左右声道错开 12ms + 微失谐做宽度。
- 主脚本的配乐策略（`find_bgm()`）：
  1. 目录里有 `bgm.{wav,mp3,m4a,aac,flac,ogg}` → 直接用（用户可放正版音源替换）；
  2. 没有 → `import bgm` 现场合成；
  3. 合成失败 → 安静出片，不阻断主流程。
- 混音命令要点：`-stream_loop -1`（音乐不够长自动循环，注意要放在第二个 `-i` **之前**）
  + `-c:v copy` + `-c:a aac -b:a 192k` + `-shortest`（以视频长度为准）。
  先编码无声 `_silent.mp4`，混完再删。
- 成品：2.6 MB / 1:08.67 / H.264 + AAC-LC 44.1kHz 立体声 192kbps。
- 校验音频不是死寂：读 wav 算 peak/RMS，并抽查几个时间点的 RMS。
